# Cubby UI

## Description
- 風格近似於 shadcn ui，但不使用任何框架，純粹使用 HTML 及 tailwind css
- 可以直接用在任何地方，不需要任何框架
- 極少量的 js，純粹用於元件動態效果

## Sytle Guide
- 風格簡約細緻，相當優雅，沒有庸俗高亮度的元素及顏色
- 某些元素有淺色的陰影，營造深淺層次
- 某些元素有圓角，營造柔和感
- 某些元素有漸層，營造顏色層次

## Tech Stack
- Tailwind CSS
- Astro
- Astro Expressive Code (Code Block Highlighting)

## 命名考慮清單
- Cubby 小盒子
- Caddy 小罐、小盒子或收納盒（如桌面整理盒）
- Framekit 框架積木
- Bitsy 小元件集合 (bitsy: 零星小東西，已有遊戲框架用此命名)
- Nibble 小口吃掉的元件
- Nook 角落小空間
- Cove 小灣、包覆空間
- Crate 木箱、收納箱 (Rust 用到了)
